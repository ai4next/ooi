# 智能起源 · 课程大纲（128 关）

> 16 章 × 8 关 = 128 关，一门完整的机器学习导论：从一个神经元到部署。每关一个概念，每关都是 Forge 里的一次真实建模、训练或评测，没有假动画。主线 40–50 小时，全收集 90 小时以上；每关 10–25 分钟。
> 规则见 [圣经 §3、§3.1、§7](../../oo_kit/docs/trilogy-bible.md)；设计见 [design.md](design.md)；逐关操作 / 通过 / ★ 指标（`levels.md`）由本表重建。

## 约定

- **标签** `章-序`：每章 8 关，固定排布：1–3 谜，4 障，5–6 谜，7 障，8 托。每章 5 谜 / 2 障 / 1 托，全作 80 / 32 / 16。
- **类：** 谜 解谜 · 障 故障（先指证再修）· 托 委托（Forge 开放题 + 展演）。
- **id：** 原有 48 个 id 原样保留为遗留 id（`chN_lM`、`chN_forge`、`ch7_sycophant`、`ch8_…`、`finale`）。其中的 N 是**旧章号**，**不再等于**现在的章号，章归属只读 `chapter` 字段。新增 80 个 id 一律写成 kebab-case `cNN-slug`（圣经 §6.1），NN 是**现在**的两位章号；两套命名互不冲突。
- **状态：** ✓ 已实现（代码里已是真实模型关，id、机制、判分不变，只换章与标签）；N 新增。
- **原有关卡的操作 / 通过条件 / ★ 指标**沿用现有 `levels.md` 中同 id 的行，本表只改写概念与错的直觉的措辞，使其符合字数上限。
- **指证**列只填故障关：回放里要指出的对象（样本点 / 一层 / 一组像素 / 一个注意力格 / 一个生成的字 / 一个训练步，少数用一个神经元或一个核）。
- **概念** ≤ 25 字，**错的直觉** ≤ 20 字。每关的初始方案或直觉做法必然失败。
- **取舍：** 每章只留最能撑起这一章的 8 关。被并入的概念写进相邻关的概念栏（如 11-5 同时含语言模型与困惑度，4-6 同时含动量与 Adam 的分参数步长），其余不再单独成关。
